# 多来源书籍生成方案

本文档记录 PDF、本地 HTML 目录和在线链接生成 GoodReader 静态书籍包的已接受设计，并作为实现与验收契约。数字 PDF、静态 HTML、公开在线链接、可选 Agent 翻译、块级原文和持久化任务队列已经落地；扫描 PDF 的本地 OCR 仍按本文边界留待后续版本。

## 已确认

### 本地生成

- GoodReader 负责书籍转换的编排和执行。
- 书籍包在用户的 Mac 上生成，不建设 GoodReader 官方云端制书服务。
- 原始 PDF、本地 HTML 目录或在线内容是书籍来源，不直接进入书架，也不会被修改。

### 完成后一次性进入书架

- 未选择翻译时，转换和契约校验完成后，静态书籍包进入书架。
- 选择翻译时，任务在书架外完成中文正文、可选对照原文和契约校验，再将完整书籍包一次性放入书架。
- 翻译失败时不静默降级，用户可以重试翻译、改为导入原文或取消任务。
- 不先发布原文书再用译文替换正文，也不默认从一次导入生成两本独立书籍。

### 由本机 Agent 运行时提供 AI 能力

- GoodReader 不配置翻译模型、API Key 或供应商账号；翻译和其他 AI 制书步骤由用户选择的本机 Agent 运行时执行。
- 制书过程使用 GoodReader 的持久任务、共享历史、隔离工作区、候选产物和确定性校验闭环。
- 同一制书任务可以在不同 Agent 运行时之间切换，并从最近检查点和候选版本继续。

### 确定性转换器与 Agent 分工

- GoodReader 的确定性转换器负责来源快照、PDF 文本提取与页面渲染、HTML 抓取与静态化、安全清理、章节与正文块 ID、图片裁切与链接完整性、`book.json` 和书籍接入契约校验。
- PDF 每页必须由用户选择的 Agent 根据页面快照和稳定来源行返回阅读顺序、语义块及完整图片裁区；Agent 不能改写正文或直接发布书籍。
- Agent 还负责用户要求的中文翻译和对照原文语义对齐。静态 HTML 和网页在不翻译时可以不使用 Agent；PDF 始终要求可用 Agent。
- GoodReader 要求每个不可移除的 PDF 来源行恰好使用一次，并校验图片裁区、资源和书籍契约，Agent 不能绕过校验。

### 在线来源范围

- 在线来源从一个公开起始链接开始，默认先分析当前页面。
- GoodReader 只在同源、同路径范围内发现候选章节；抓取前展示章节标题与 URL，由用户确认或排除。
- 用户可以明确选择只导入当前页面。
- 外部网站链接不作为章节继续抓取；页面直接依赖的图片和样式资源可以下载到候选书籍包。
- 首版不处理登录、付费墙或需要人工交互才能访问的内容，也不执行整站无限抓取。

### 在线来源的转换时渲染

- 优先解析服务器返回的静态 HTML；静态 HTML 不含完整正文时，可以在隔离浏览器环境中运行页面脚本并等待正文稳定。
- 隔离环境不使用用户日常浏览器的 Cookie、登录状态或本地存储，不能访问本地文件或 GoodReader 数据。
- 页面网络请求限制在用户已确认的在线来源范围及其必要资源。
- 达到超时、页面持续变化或需要登录与人工交互时停止，并报告无法自动抓取。
- 获取稳定 DOM 后立即静态化，移除脚本、事件、表单和主动嵌入内容；正式书籍只执行 GoodReader 自己的阅读脚本。

### 本地 HTML 的转换时渲染

- HTML 已包含完整正文时直接静态解析，不运行原始脚本。
- 正文由 JavaScript 生成时，可以在隔离转换环境中运行脚本并保存生成后的静态 DOM。
- 脚本只能读取来源快照目录中的文件，不能访问源目录之外的本机文件；默认禁止联网。
- 内容生成依赖网络时，任务暂停并列出所需域名，由用户决定是否授权。
- 搜索、动画、测验、在线编辑器等专有交互不转换；目录、翻页、主题、标注和原文等通用阅读行为由 GoodReader 接管。
- 最终书籍不保留原始脚本，只保留静态内容、CSS、图片、字体和受支持的声明式数据。

### PDF 来源范围

- 产品范围最终覆盖带文本层的数字 PDF、页面为图像的扫描 PDF，以及两者并存的混合 PDF。
- 书籍生成前执行 PDF 预检，报告总页数、PDF 类型和需要 OCR 的页面。
- 第一阶段实现数字 PDF 转换；扫描页依赖可配置的本地 OCR 模型，本地 OCR 能力延后开发。
- OCR 属于本地内容提取能力，不复用或改变 Agent 运行时的账号、API Key 与模型配置边界。
- OCR 只负责从页面图像提取内容，不翻译或重绘图片本身。
- 本地 OCR 不可用时，扫描 PDF 在预检后暂停；混合 PDF 只要存在包含正文但无可用文本层的页面，也暂停整个生成任务。
- 不生成只包含可提取页面的残缺书籍。预检报告列出需要 OCR 的页码，保留任务选择，未来具备 OCR 能力后可以继续。
- 纯图片插图不视为缺失正文页，应作为书籍资源正常保留。

### PDF 转换目标

- PDF 转换为语义化、可重排的连续阅读 HTML，不逐页复刻 PDF 的字体、换行、分页和坐标。
- 每个选中页面单独调用 Agent；输入为页面快照、尺寸及带稳定 ID 的来源行，输出只包含块类型、行 ID 顺序和图片像素裁区。
- 转换应恢复章节、标题、段落、列表、表格、引用、脚注、图片、图注和正确阅读顺序，并移除重复页眉、页脚、页码及装饰。
- 多栏页面恢复为单一语义阅读顺序；图片按正文位置插入。
- 来源页码作为内部溯源信息保留，用于质量检查和问题定位，不作为正文展示结构。
- 无法可靠恢复阅读顺序或复杂结构的页面进入质量报告和预览，不能静默生成语义错误的正文。

### PDF 章节恢复

- 优先使用 PDF 自带书签、目录和可可靠识别的一级标题生成章节候选。
- 确定性规则无法消除结构歧义时，有可用 Agent 则由 Agent 根据目录页、标题层级和正文提出章节方案；没有 Agent 时由用户在结构确认页按标题或页码建立章节。
- 章节方案必须在翻译开始前由用户确认。
- 用户可以明确选择整本作为一个章节，但 GoodReader 不默认这样做，也不采用固定页数切章等无语义依据的规则。

### PDF 图片完整性

- 正文引用的 Figure、图表、示意图、截图、照片、地图、带图注或编号的图片，以及其他承担说明作用的语义图片必须保留。
- 重复出版社 Logo、页面背景、分隔线、装饰图案和页眉页脚中的重复图标可以排除。
- Agent 逐页查看来源视觉并返回承担信息的完整视觉单元裁区；重复 Logo、背景和装饰可以明确排除。
- GoodReader 按 Agent 返回的页面像素裁区高质量渲染视觉单元，避免直接提取图层造成矢量、文字或组合内容缺失。
- 生成后校验图片文件存在且被 HTML 引用，并检查正文中的 Figure 引用是否存在对应视觉内容。

### 语言判断

- GoodReader 按整本来源的主叙述语言判断，而不是按是否出现中文字符或英文字符判断。
- 判断结果分为“中文为主”“非中文为主”和“混合或无法确定”三种。
- 代码、命令、专有名词和少量引用不改变主叙述语言判断。
- 中文为主时不提示翻译；非中文为主时询问是否翻译为简体中文；混合或无法确定时由用户选择保持原样或将非中文主内容翻译为简体中文。
- 导入确认页展示检测结果，并允许用户在生成前手动覆盖。

### 翻译目标语言

- 首版目标语言固定为简体中文，界面使用“翻译为简体中文”而不是含糊的“翻译为中文”。
- 来源语言不限；实际翻译能力取决于用户选择的 Agent 运行时，无法处理时任务暂停且不静默切换运行时。
- `book.json` 和对照文本使用标准语言代码记录主正文与来源语言；任务模型保留 `targetLanguage`，为未来增加其他目标语言预留边界。

### 正文块级原文

- 翻译后的中文是主正文；用户选择“支持显示原文”时，来源原文按章节和正文块保存为只读对照文本。
- 用户选中中文后，GoodReader 显示选区所在正文块对应的完整原文，不做选中文字级的双语对齐。
- 对照原文不参与阅读进度，也不能添加高亮、笔记或书签。
- 支持显示原文需要额外完成来源分块、译文与原文对齐及完整性校验，因此生成时间长于仅生成中文正文。
- 对照原文采用尽力生成，允许只覆盖部分正文块；缺少映射不阻止书籍进入书架。
- 文字选择工具栏始终显示地球仪。当前正文块有对照原文时可以点击；没有时置灰、不可点击，并说明“当前内容没有可用原文”。
- 中文书和未选择保留原文的译书不生成对照文本，其正文块的地球仪保持置灰。

### 正文翻译范围

- 翻译章节标题、各级标题、正文段落、列表与表格中的说明文字、引用、提示框、脚注、图注及有说明价值的图片替代文字。
- 代码块、行内代码、命令、文件路径、URL、标识符、API 名称、数学公式、结构化数据和配置示例保持原样。
- 导航、广告、页头、页脚等非正文内容先在内容提取阶段排除，不进入翻译。
- 图片文件及图片中的文字不属于当前正文翻译范围；图片 OCR 或重绘另行决策。
- 书名、作者等书架元数据采用独立规则，不由正文翻译规则隐式决定。

### 翻译完成标准

- 转换阶段先建立正文块账本；每个来源正文块必须对应一个保持相同稳定 ID 的译文正文块。
- 代码、命令、URL、公式等受保护内容进行确定性比较，误改时校验失败。
- 图片、图注、脚注和内部链接必须仍然存在；不允许正文块缺失，也不允许无来源新增正文。
- 未选择显示原文时仍保留任务内部的块对应关系，但不把来源原文写入正式书籍的对照文本。
- GoodReader 检测明显漏译、异常短译文和语言不符，但不把自动检查表述为语义翻译质量保证。
- 生成完成后提供章节目录和抽样预览，重点展示标题、长段落、表格、图注和警告项。
- 用户可以接受、要求当前 Agent 修改或切换 Agent 接续；只有确定性完整性校验通过并经用户确认后，书籍才进入书架。

### 翻译执行协议

- PDF 排版使用页级隔离工作区：Agent 只读取 `input/page.png` 与 `input/page.json`，只写 `output/page.json`；GoodReader 校验后生成最终内容并保存页级检查点。
- Claude Code 与 Codex 的内置适配器使用结构化输出协议；翻译步骤由 GoodReader 直接提供正文块输入并接收符合 Schema 的译文，不允许 Agent 自行修改候选书籍。
- Cursor 与自定义 CLI 在不支持结构化输出时继续使用标准文件契约，并由 GoodReader 执行相同的正文块账本校验。
- 翻译按字符量和正文块数自适应分批；全局仍只运行一个书籍生成任务，但任务内部最多并行两个独立翻译批次，结果按正文块稳定 ID 确定性合并。
- 受保护片段必须保持标识和值完整且各出现一次，允许随目标语言语序重新排列；失败批次可以自动二分后重试。
- Agent 进程、检查点和事件由 GoodReader 持有；暂停、取消或应用重启必须终止遗留进程，不以 CLI 私有会话作为完成状态。

### 失败与降级

- 译文失败或正文块账本不完整时，候选书籍不能进入书架；任务暂停并保留检查点、来源快照和候选结果。
- 用户可以让当前 Agent 重试、切换 Agent 接续、明确改为导入原语言书籍，或取消任务；GoodReader 不自动改变翻译选择。
- 中文主正文完整时，对照原文允许部分覆盖。质量报告列出成功与缺失映射的章节和正文块数量，用户可以重试或知情接受；缺失块的地球仪置灰。
- 如果没有任何原文块成功生成，用户必须明确选择“继续但不支持显示原文”，不能把任务标记为已经实现原文功能。

### 工作量、进度与时间提示

- 任务开始前展示页数、章节数、正文块数和大致字数；PDF 明确提示会逐页调用 Agent，并对“逐页排版”“逐页排版并翻译”“逐页排版、翻译并支持显示原文”给出相对耗时说明。
- 开始前不承诺不可靠的精确分钟数，明确说明任务可以后台运行并从检查点恢复。
- 运行中展示真实阶段和可验证计数，例如已完成章节数或已对齐正文块数。
- 完成前几个检查点后，根据当前 Agent 运行时的实际吞吐动态计算剩余时间。
- Agent 运行时不提供细粒度事件时，只显示已完成检查点，不伪造百分比或 ETA。
- 支持结构化事件的运行时还展示当前批次、正文块和字符计数、执行耗时、动态 ETA、运行时会话及最近活动；事件以追加日志持久化并按序号增量读取。

### 导入向导

1. 用户选择 PDF、本地 HTML 目录或在线链接作为书籍来源。
2. GoodReader 创建来源快照并预检可访问性、PDF/OCR 状态、动态渲染需求和基本安全问题。
3. 结构确认页展示书名、原始书名、作者、封面、章节标题与顺序、图片数量、字数和语言判断；用户可以编辑元数据，重排、重命名或排除章节。在线来源在此确认 URL 清单。
4. 用户选择保持原语言或翻译为简体中文；翻译时继续选择是否支持显示原文，并查看工作量和相对耗时。
5. PDF 必须选择逐页排版 Agent；HTML 和在线来源只在翻译等 AI 步骤中选择 Agent。
6. 任务在后台按检查点执行转换、翻译、原文对齐和校验。
7. 用户查看质量报告、抽样正文、图片、目录和对照原文预览，确认后一次性进入书架。

进入翻译阶段后修改章节结构会使后续结果失效；用户返回结构确认时，从该检查点重新生成下游结果。

### 任务队列

- 用户可以连续创建多个持久化书籍生成任务；来源预检、语言判断和结构确认可以立即执行。
- PDF 转换、Agent 翻译和原文对齐等重型生成阶段首版全局同时只运行一个任务，其他任务进入可调整顺序的队列。
- 当前任务暂停、失败或等待用户确认时，队列运行下一项；用户可以暂停或取消排队任务。
- 书籍阅读和普通 AI 问答不进入书籍生成队列，继续正常使用。
- 是否开放可配置并发留待真实性能数据验证后决定。

### 质量报告分级

**错误——必须修复，不能入架：**

- 书籍接入契约或安全校验失败；页面、章节或正文块缺失。
- 翻译正文块账本不完整，或代码、公式、URL 等受保护内容被误改。
- 正文引用的语义图片缺失，或阅读顺序无法可靠确定。
- 扫描正文页需要 OCR 但本地 OCR 不可用。
- 最终候选包仍包含原始脚本或危险主动内容。

**警告——用户预览后可以接受：**

- 部分正文块没有对照原文。
- 复杂表格被简化，或标题层级、图注和脚注识别置信度较低。
- 缺少来源封面而使用生成封面，或装饰图片被排除。
- 个别外部链接无法访问但不影响正文完整性。
- 语言判断、作者或其他元数据存在不确定性。

错误不能通过“仍然导入”绕过；警告必须提供位置与预览入口，并由用户明确接受。

### 翻译书的书架元数据

- 翻译书的展示书名默认使用中文译名，并允许用户在生成前编辑。
- 来源书名作为原始书名保留；书架搜索同时匹配展示书名与原始书名。
- 作者默认保留来源拼写，不自动音译，用户可以在生成前编辑。
- 阅读界面以展示书名为主，原始书名可以作为次要信息展示。
- 未选择翻译时保持来源书名，不额外生成原始书名字段。
- `book.json` 增加可选 `originalTitle` 字段；旧书籍不受影响。

### 封面

- PDF 优先使用内嵌封面，没有时将第一页高质量渲染为封面候选。
- 本地 HTML 优先使用已有 `book.json`、页面元数据或明确的封面图片；在线来源优先使用 `og:image`、结构化书籍元数据或入口页主封面。
- 存在多个候选时由用户在结构确认页选择，用户也可以另选本地图片。
- 没有可靠封面时，GoodReader 根据展示书名、作者和稳定配色生成确定性排版封面，不调用 Agent 或 AIGC。
- 横图或尺寸异常图片适配到统一封面画布，不强行裁掉有意义内容。
- 翻译书的生成封面使用中文展示书名；原始封面上的文字不修改。

### 重复来源与重新生成

- 每次完成新的书籍生成任务都创建新的书籍 UUID，不沿用旧 UUID 覆盖书籍内容。
- GoodReader 可以根据来源信息提示“可能已经导入”，但不自动阻止用户继续生成。
- 新旧书籍可以并存比较；不自动迁移旧书的阅读进度、阅读标注或书籍 AI 工作区。
- 用户确认新版本可用后，可以按现有规则单独移除旧书。
- 书籍升级、版本关联和标注迁移如果未来需要，应作为独立能力设计，不能由普通导入隐式完成。

### 来源快照生命周期

- 生成开始时，GoodReader 在任务工作区保存不可变的来源快照，后续转换、翻译和校验都使用该快照。
- 任务暂停或失败时保留来源快照，以便恢复；用户取消任务时删除快照和候选产物。
- 候选书籍校验通过并被用户接受后，删除 PDF、本地 HTML 目录或网页的任务快照。
- 正式书籍包保留完整阅读内容、图片及用户选择的对照原文，不依赖原始来源继续存在。
- 数据库保留来源类型、文件名或 URL、获取时间、来源指纹和质量报告；本地绝对路径不写入 `book.json`。
- 用户自己的 PDF 或 HTML 目录始终保持不变，GoodReader 不负责删除。

### 任务暂停、恢复、取消与清理

- 书籍生成任务及其队列状态持久化；关闭 GoodReader 窗口不等于取消任务，本地任务执行器继续运行，重新打开窗口后恢复任务、当前阶段、检查点和用户上次查看的位置。
- 用户暂停任务时，GoodReader 在最近可验证检查点停止继续调度，保留来源快照、结构选择、候选产物、质量报告和已完成检查点。
- 用户恢复任务时从最近有效检查点继续；若该检查点使用的 Agent 不可用，任务停留在暂停状态，允许用户切换 Agent 后继续。
- 任务失败时保留来源快照、候选产物和检查点，并明确失败阶段；用户可以重试、切换 Agent、按已确认规则降级，或取消。
- 等待结构确认、质量警告确认或降级确认的任务不占用全局重型生成槽位，队列继续处理下一项。
- 用户取消任务时终止当前生成步骤，丢弃尚未形成有效检查点的结果，并删除 GoodReader 管理的来源快照和候选产物；用户自己的来源文件或目录不受影响。
- 候选书籍只有在硬错误清零、警告经用户确认并完成最终接入契约校验后，才原子化进入书架；随后清理任务来源快照和临时候选产物。
- 已进入书架的正式书籍不受对应生成任务的暂停、取消或清理操作影响，删除书籍仍遵循现有书架删除规则。

## 实施分期

### 第一阶段：契约与任务基础

- 扩展 `book.json` 与对照文本契约，支持来源语言、目标语言、原始书名和正文块级原文。
- 建立来源快照、正文块账本、持久任务、检查点、单并发重型队列和质量报告。

### 第二阶段：本地来源与数字 PDF

- 将现有本地 HTML 导入纳入统一生成流程。
- 实现带文本层数字 PDF 的逐页 Agent 语义排版、章节确认和图片完整性校验。
- 识别扫描页和混合 PDF；需要 OCR 时正确暂停并报告页码，暂不实现 OCR 转换。

### 第三阶段：在线来源

- 实现同源同路径的候选章节发现、URL 清单确认和资源本地化。
- 实现静态解析优先、必要时隔离动态渲染，以及最终内容静态化和安全清理。

### 第四阶段：Agent 生成能力

- 接入 PDF 逐页排版、简体中文翻译、正文块级原文对齐、动态 ETA、预览和跨 Agent 检查点恢复。
- 保持确定性转换器负责内容完整性、受保护内容、资源引用和书籍接入契约的最终校验。

### 第五阶段：端到端验收

- 为数字 PDF、本地静态与动态 HTML、静态与动态在线来源建立固定验收样本。
- 覆盖翻译与不翻译、完整与部分原文、失败恢复、切换 Agent、队列、取消清理和原子入架。
- 第一版完整的多来源书籍生成功能必须在前四阶段通过端到端验收后发布；本地 OCR 模型配置和扫描 PDF 实际转换继续留在后续版本。
