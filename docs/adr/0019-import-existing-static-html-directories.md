# 从现有静态 HTML 目录转换导入

GoodReader 提供目录选择入口，将用户选中的现有静态 HTML 目录复制到书库临时目录；源目录始终保持不变。转换器为每次导入分配新的 UUID，从 HTML 推断标题、作者、封面、入口和章节顺序，补齐章节与正文块锚点，移除脚本及主动内容，生成唯一权威的 `book.json`，再以现有契约校验完整结果。与章节同名、且严格声明为 `window.EN_TEXT` 纯文本数组的旧版 `.en.js` 会在不执行脚本的前提下转换为只读对照文本 JSON；模板表达式、异常语法或正文块数量不一致时拒绝转换。只有校验通过的临时目录才会原子移动为正式书籍包，因此失败或中断的导入不会产生半本书。

V1 的转换目标是静态化并接入 GoodReader 通用阅读能力，不承诺翻译任意 JavaScript 的专有行为。缺少封面时使用 GoodReader 默认封面；推断或安全处理结果在导入完成界面中明确告知用户。
