# 确定性转换为主，Agent 按需处理语义工作

GoodReader 使用自身确定性组件完成来源提取、静态化、稳定标识生成、图片与链接检查及书籍契约校验，只在翻译、原文对齐和疑难结构修复等语义工作中调用本机 Agent。把全部制书交给 Agent 虽然实现直接，但难以证明内容没有遗漏或误改；确定性转换与 Agent 候选修复分层后，干净来源无需 AI 也能导入，Agent 也不能绕过校验直接完成书籍。

PDF 页面排版部分已由 ADR 0028 修订：每页必须调用 Agent 判断阅读顺序、语义块和图片区域，但来源行账本、图片裁切、HTML 生成与最终校验仍由 GoodReader 确定性执行。
