# 阅读主题只在运行时应用

GoodReader 的阅读界面默认跟随 macOS 外观，并在统一阅读栏提供明亮／黑暗切换；手动选择以 `reader-theme` 设置写入 SQLite。主题同时覆盖 GoodReader 控件与书籍页面的语义颜色变量，并为页面背景、正文、加粗文本及书籍自带的语义导航区域提供安全兜底。即使书籍把侧栏背景写成固定浅色，或给加粗文本写死黑色，运行时也会在黑暗模式下映射为对应的暗色表面与正文颜色，但不会改写书籍目录中的 HTML、CSS、图片或其他内容。

主题转换保持书籍的结构、字体、栏宽、间距和图像不变，暗色使用低白光的深灰表面而非纯黑反转，并单独保证正文、次要文字、边框、焦点和标注颜色的可辨识度。
