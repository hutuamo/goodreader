# PDF 每页由 Agent 生成结构化阅读布局

GoodReader 对每个选中的 PDF 页面生成页面快照与带稳定 ID 的来源文本行，并调用用户选择的本机 Agent 返回阅读顺序、语义块类型和完整图片裁区。Agent 不直接生成最终正文，也不能改写来源行；GoodReader 要求每个不可移除的来源行恰好出现一次，校验裁区位于页面范围内，再确定性生成 HTML 和图片。每页通过校验后保存独立检查点，失败、暂停或切换 Agent 时从最近完成页继续。

该决策取代 PDF 的纯脚本排版和基于图注规则的图片截取。章节预检、PDF 文本提取、页面渲染、来源行账本、裁图、书籍契约和发布仍由 GoodReader 控制；扫描页仍需先通过本地 OCR 获得可校验文本。
