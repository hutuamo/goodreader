# GoodReader 独占浏览器中的阅读脚本执行

静态书籍包不得直接运行自带 JavaScript，浏览器中只有 GoodReader 发布的统一阅读脚本可以执行；带脚本的既有内容必须先经过书籍转换与安全检查，不能原样导入。相比允许用户信任的脚本直接运行，这会增加旧书适配成本并放弃任意网站兼容性，却消除了双阅读器、双状态源和书籍脚本接触本地接口的风险，让进度与三类阅读标注始终由 GoodReader 统一控制。

目录导入会确定性地删除自带脚本、行内事件和主动嵌入，并把章节与正文块接入 GoodReader 统一运行时，但不尝试翻译任意 JavaScript 的业务语义。依赖脚本生成正文或专有交互的内容仍需在制书阶段转为静态 HTML 或声明式数据。转换后的书籍必须再次通过契约与安全校验，运行时浏览器安全策略继续阻止遗漏的书籍脚本。
