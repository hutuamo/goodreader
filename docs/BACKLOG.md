# Backlog

## 加强未知来源书籍的供应链验证

当前版本禁止静态书籍包直接运行自带脚本，并在书籍转换时执行安全检查。后续评估来源签名、可复现打包和发布者信任机制，进一步确认内容来源与完整性。

## 跨书全文搜索

V1 的书架搜索只按书名和作者过滤，不索引章节正文。后续评估中文检索、对照文本范围、结果片段与正文定位。

## 校验已导入书籍的内容完整性

V1 约定书籍内容不可变，但不主动计算或比较内容指纹。后续评估首次导入指纹、相同 UUID 内容变更检测，以及与书籍来源验证之间的边界。

## 配置本地 OCR 能力

PDF 书籍生成最终需要覆盖扫描 PDF 和包含扫描页的混合 PDF。后续提供本地 OCR 模型的配置、运行和质量报告能力；OCR 只承担本地内容提取，不并入 Agent 运行时的账号、API Key 或模型配置。
